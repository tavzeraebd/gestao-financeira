# Achados de segurança

Tabela lida pelo security gate. **Alto** ou **crítico** com status `aberto` bloqueia a entrega.
Severidade: `crítica` | `alta` | `média` | `baixa`. Status: `aberto` | `corrigido` | `aceito`.

`aceito` é decisão do usuário, com motivo e data; não bloqueia, mas fica registrado.

Nunca colar segredo, token ou dado real na coluna Achado — descreva, não exponha.

## Notas

- SEC-12 (`user_metadata.next_path` no link de `supabase/templates/confirmation.html`) foi avaliado e não é achado: sem consequência demonstrável. A validação em `signUp` não é controle, porque o Auth aceita metadata arbitrário chamado direto com a publishable key; o que protege é (a) o escape de URL do template (`html/template`) e (b) `safeNextPath` revalidando o destino em `src/app/auth/confirm/route.ts:36`.
