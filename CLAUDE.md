
## Agentic Software Factory

Este projeto usa a fábrica global: `~/.claude/factory/CONTROL-PLANE.md`.

- Tarefas de desenvolvimento passam pelo Orchestrator (skill `/factory`).
- Memória **deste projeto**: `.claude/factory/project-memory/` (decisões, convenções, requisitos).
- Aprendizado reutilizável não entra aqui: vira proposta em `~/.claude/factory/learning/proposals/`.
- Convenções deste projeto têm precedência sobre as preferências dos agentes.
